# Quick Start Guide - AI Features

## 🚀 Get Started in 3 Steps

### Step 1: Build the App
```bash
1. Open Xcode
2. Build and run (⌘ + R)
3. App opens with refined UI + AI features
```

### Step 2: Try the Features

#### Natural Language Chat
```
1. Tap "AI Chat" tab (sparkles icon)
2. Type: "How much is 100 USD in EUR?"
3. AI responds instantly
4. Check Convert tab - values are filled!
```

#### Smart Suggestions
```
1. Make a few conversions (USD→EUR, etc.)
2. Restart the app
3. Convert tab shows suggestion cards
4. Tap any suggestion for instant conversion
```

#### Travel Assistant
```
1. Go to Tools tab
2. Enter "Paris" as destination
3. Enter "1500" as budget
4. Tap "Generate Insights"
5. See full breakdown + recommendations!
```

### Step 3: Explore More

#### Rate Trends
- Make conversions → builds history
- Convert tab shows trend predictions
- Green = Rising, Red = Falling, Blue = Stable

#### Alert Recommendations
- Build history (5-10 conversions)
- Tools tab shows smart alert suggestions
- One-tap to add recommended alerts

## 🔍 Troubleshooting

### "No suggestions showing"
- **Reason**: Need usage history
- **Fix**: Make 5-10 conversions, restart app

### "Rate trend not appearing"
- **Reason**: Need historical data
- **Fix**: Use app for few days to build history

### "Travel insights loading"
- **Reason**: Calculations in progress
- **Fix**: Wait 1-2 seconds, should appear

### "AI chat not responding"
- **Reason**: Query not understood
- **Fix**: Try simpler phrasing like "100 USD to EUR"
